# BORA (Build Once Run Anyway)
## The way Desktop Applications are meant to be
Are you tired of figuring out different ways to make your C++ windows code work on a mac? Or any other way around. *Well, you aren't going to use any of that code anytime soon*

BORA redesigns C++ and its STL to run anywhere while building only once.

### How to get started
First, run the get command, if you are on windows, run get.bat, otherwise use get.sh
Once that's done, you have the full source code readily available. This is the recommanded way on modifying and updating bora while still keeping it seperate.
